Drop your real images in this folder, then reference them from /content/site.js.

Recommended files:
  logo.png        -> set brand.logoImage      = "/images/logo.png"
  sabbir.jpg      -> set about.image          = "/images/sabbir.jpg"   (portrait, ~4:5)
  og-image.jpg    -> used for social sharing   (1200 x 630 px)
  project-1.jpg … -> set portfolio.web[n].image / portfolio.video[n].image

Also add a favicon by placing `favicon.ico` inside the /app folder
(Next.js picks it up automatically).
